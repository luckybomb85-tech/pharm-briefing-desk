# 데일리팜 제약바이오 브리핑 데스크 — 재구축 v2

기존 브리핑의 디자인 콘셉트(브랜드, 날짜 탐색, 국내·글로벌·특허 탭)를 유지하며 새 데이터 파이프라인을 구축합니다.

## 격리 원칙
- 화면은 오직 `v2/data/YYYY-MM-DD.json`만 읽습니다. 기존 `data/`, `global/`, `domestic/`, `live/` 파일은 사용하지 않습니다.
- 데이터 계약은 `v2/SCHEMA.json`을 따릅니다. `schema_version=briefing-v2`가 아니면 거부합니다.
- 수집하지 않은 날짜는 빈 상태로 표시합니다. 가짜 기사, 제목만 반복하는 요약, 이전 날짜 기사 재활용을 금지합니다.
- 실제 기사 수집·요약·검증·발행 파이프라인은 아직 연결되지 않았습니다. 기존 예약작업은 재사용하지 않습니다.
- 원문 URL은 HTTP(S)만 허용하고 기사 텍스트는 HTML 이스케이프합니다.

## 재구축 순서
1. 읽기 전용 화면과 데이터 계약 확립 (완료: 코드 반영)
2. 국내 기사 수집 및 원문 확인·중복 제거
3. 검증된 원문 기반 요약과 품질검사
4. 글로벌 기사 번역·특허 분류
5. 기사화 기능(실제 생성·오류 처리 포함)
6. 수동 배포 통합검증 후 아침 자동화 재설계

**주의:** GitHub 코드 반영은 실제 운영 사이트 배포·브라우저 검증 성공을 의미하지 않습니다.
