설정

이 간격은 이 기기의 화면 업데이트 주기야. 서버의 FDA 원문 자동 수집은 현재 1시간·3시간 간격으로 유지돼. 서버 전체 주기 변경은 관리자 권한이 필요해.

FDA 자동알림

기기의 알림 상태를 확인합니다.

아이폰 · 아이패드에서 설정
  1. 이 페이지를 Safari에서 열어.
  2. Safari 하단 공유 버튼(□↑)을 눌러.
  3. 홈 화면에 추가를 선택해.
  4. 홈 화면의 FDA 모니터링 앱을 실행한 뒤 🔔을 눌러 알림을 허용해.
갤럭시 · 안드로이드에서 설정
  1. Chrome 또는 삼성 인터넷에서 이 페이지를 열어.
  2. 🔔 버튼을 누르고 알림을 허용해.
  3. 차단됐으면 브라우저 설정 → 사이트 설정 → 알림을 허용해.
  4. 기기 설정 → 앱 → 사용 중인 브라우저 → 알림도 켜져 있는지 확인해.
브라우저 알림 안내

이 사이트에 대한 알림 권한을 허용해. 이미 차단했다면 브라우저의 사이트 권한에서 알림 차단을 해제해.
